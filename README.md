# TOO TAS — корпоративный сайт

Многоязычный продающий сайт компании TOO TAS: поставка инертных материалов, товарного бетона, асфальта и транспортная логистика по Астане и Акмолинской области.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Статическая сборка

```bash
npm run build
```

Готовые файлы появятся в каталоге `out` и могут быть размещены на любом статическом хостинге.
